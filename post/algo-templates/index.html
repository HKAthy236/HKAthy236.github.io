算法竞赛模板库：C++ 与 Python 双语言对照

打比赛最烦的事，不是想不出做法，而是明明会写却写错——并查集的路径压缩漏了一行、线段树的 pushdown 传错参数、KMP 的 next 数组下标又对不上了。

这些模板我都默写过几十遍，但每次还是会有细节翻车。所以我干脆把它们整理成了一个站，写题时直接查、直接复制。

在线地址：Algo Templates 算法竞赛模板库

收录了什么

按五个分类归档，覆盖平时最常打交道的几类问题：

分类 模板
数据结构 并查集、树状数组、线段树、ST 表
图论 倍增 LCA、堆优化 Dijkstra、拓扑排序、Tarjan 强连通分量
动态规划 背包问题（0/1、完全、多重、分组）、数位 DP、最长上升子序列
字符串 字符串哈希、KMP、Z 函数
数学 快速幂与矩阵快速幂、扩展欧几里得、线性筛素数

选的都是出现频率最高的那批。像网络流、平衡树、后缀自动机这些要么太偏、要么变体太多，放进来反而会让查找变慢。模板库会持续补充，具体收录情况以站内为准。

每个模板都是双语言

这是我觉得最实用的一点：同一个模板，C++ 和 Python 两份实现并排放在一起，点标签就能切换。

打比赛主用 C++，但平时刷题、写题解、或者临时用 Python 验证思路时，能直接对照着看，不用自己翻译一遍。

以并查集为例：

C++

struct DSU {
    vector<int> fa, sz;
    explicit DSU(int n) : fa(n + 1), sz(n + 1, 1) {
        iota(fa.begin(), fa.end(), 0);
    }
    int find(int x) {
        while (x != fa[x]) x = fa[x] = fa[fa[x]];
        return x;
    }
    bool merge(int a, int b) {
        a = find(a), b = find(b);
        if (a == b) return false;
        if (sz[a] < sz[b]) swap(a, b);
        fa[b] = a, sz[a] += sz[b];
        return true;
    }
};

Python

class DSU:
    def __init__(self, n):
        self.fa = list(range(n + 1))
        self.sz = [1] * (n + 1)

    def find(self, x):
        while x != self.fa[x]:
            self.fa[x] = self.fa[self.fa[x]]
            x = self.fa[x]
        return x

    def merge(self, a, b):
        a, b = self.find(a), self.find(b)
        if a == b:
            return False
        if self.sz[a] < self.sz[b]:
            a, b = b, a
        self.fa[b] = a
        self.sz[a] += self.sz[b]
        return True

两边都是路径压缩 + 按大小合并，find 均摊复杂度 O(α(n))——反阿克曼函数，实际上就是个常数。

几个设计上的取舍

代码要能直接粘进评测机

代码块右上角有复制按钮，而且复制内容不含行号。这个细节听起来很小，但如果你从某些博客复制过带行号的代码，就知道有多烦。

全文搜索走本地，不依赖第三方

用的是 VitePress 内置的 local search，构建时把索引打进产物。好处是：

  • 不需要 Algolia 那种第三方账号和 API Key
  • 断网也能搜
  • 纯静态，部署到 GitHub Pages / Vercel 都行

数学公式用 MathJax3

复杂度推导经常要写公式，比如 O(n log n)、O(α(n))、调和级数求和这类。行内和块级公式都能正常渲染，写复杂度分析不用再贴图片。

暗色模式

读代码的场景，暗色其实更舒服。跟随系统，也可以手动切。

怎么用最顺手

我自己的习惯是两个场景：

  1. 写题时——忘了某个细节（比如树状数组的 lowbit 到底是 x & -x 还是 x & (x-1)），直接搜索跳过去看一眼，复制走；
  2. 复习时——按分类从头过一遍，确认每个模板都还能默写出来。

第二种场景更值得做。模板这种东西，会写和写对之间差着一次比赛的名次。

最后
